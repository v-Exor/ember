# Data, imagery, and result provenance

This project covers only CSST106 Laboratory Exercise 5, Principal Component Analysis in Computer Vision, based on `CSST106_Lab_Experiment_05_PCA_in_CV.docx`, weeks 7–8, first semester, AY 2026–2027.

## Faces

All face images and hero illustrations derive from the Labeled Faces in the Wild (LFW) funneled dataset, loaded using scikit-learn's `fetch_lfw_people(min_faces_per_person=70, resize=0.4)`. These are academic dataset images, not original photographs created for this site. No ownership of the original photos is asserted. Consult the original dataset's usage information for redistribution beyond this educational project.

- Dataset documentation: https://scikit-learn.org/stable/datasets/real_world.html#the-labeled-faces-in-the-wild-face-recognition-dataset
- Loader documentation: https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_lfw_people.html
- Original LFW project: http://vis-www.cs.umass.edu/lfw/
- PCA documentation: https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html
- SVC documentation: https://scikit-learn.org/stable/modules/generated/sklearn.svm.SVC.html

No school logo, school watermark, or embedded image from the Word file is included. The favicon is the same generic geometric VisionLab mark used in the user's other laboratory websites. The hero's tiny SVG curve is illustrative; the result plot is calculated from genuine model variance values.

## Genuine trained artifacts

`python/export_model.py` reproduces the fitted model from the conversation's solution. `assets/data/manifest.json` records library versions, split indices, labels, settings, array shapes/offsets, SHA-256 hashes, and all 258 reference predictions. `faces.bin` preserves the exact float32 input pixels; `model.bin` contains the fitted PCA and SVM numerical arrays. Training/test membership is fixed and disjoint.

The four PNG figures in `assets/results` and the TXT report were generated by the original completed Python activity. They are clearly labeled saved results. The hero reconstruction uses 50 retained components. Browser live projection, inverse projection, RBF SVM voting, and evaluation are implemented in `processing.js`, `worker.js`, and `app.js`; they are not simulated responses.

## Browser software

The deployed website uses only original HTML, CSS, JavaScript, Web Workers, and Canvas. It has no external runtime libraries, remote fonts, analytics, or upload service. Node development dependencies (Playwright and axe) are used only for validation and are not served in the production workflow. Their licenses remain in their respective packages.
